===== RESOURCE-SOURCES.txt =====

ブロピア！ Blockopia v8 — resource sources / attribution

Game logic, world generation, browser controls, voxel rendering integration,
inventory implementation and reconstructed 3D rigs: Blockopia project
(previous releases were named BLOCKWILD).

Minecraft reference artwork
----------------------------------------
Primary reference version: Minecraft Java Edition 1.12.2
Supplemental Warden texture: Minecraft Java Edition 1.19
https://raw.githubusercontent.com/InventivetalentDev/minecraft-assets/1.19/assets/minecraft/textures/entity/warden/warden.png
Warden body proportions and skin-layout reference:
https://github.com/mahtomedi/minecraft/blob/main/src/main/java/net/minecraft/client/model/WardenModel.java
Reference Java source is not included in the game package.
Minecraft textures and GUI artwork: Mojang Studios / Microsoft.
These assets are not covered by the Three.js MIT license.
Blockopia is an unofficial browser game and is not an official Minecraft release.

Public version manifest used to locate the reference client:
https://piston-meta.mojang.com/mc/game/version_manifest_v2.json
Reference client URL:
https://piston-data.mojang.com/v1/objects/0f275bc1547d01fa5f56ba34bdc87d981ee12daf/client.jar
Verified reference client SHA-1:
0f275bc1547d01fa5f56ba34bdc87d981ee12daf

Selected block, item, entity and GUI PNG resources from
assets/minecraft/textures/ are embedded as data URLs in index.html.
Small icon/color/cuboid adaptations are generated from those PNGs.
The reference JAR, Minecraft Java bytecode and the original game client
are not included in this package.

https://i.imgur.com/Q65qb67.png
These research screenshots are not included as game textures.

Sound reference assets
----------------------------------------
Selected Minecraft Java Edition 1.12 sound effects: Mojang Studios / Microsoft.
113 selected resources are converted from OGG to MP3 for browser compatibility
and embedded in index.html. Each original OGG download was checked against
its asset-index SHA-1 before conversion. MP3 encoding: 128 kbps / 44.1 kHz.
Asset-index source:
https://piston-meta.mojang.com/v1/packages/a21e1ded1a24ea1548dd8db0cf30b6acb02655a9/1.12.json
Asset files:
https://resources.download.minecraft.net/<first-two-hash-characters>/<sha1>
Additional v8 effects include attack, anvil, enchantment, advancement,
ender-eye insertion, End portal opening and Nether portal travel cues.
End music: music/game/end/boss and music/game/end/credits (120-second
excerpts with fades, MP3 128 kbps). Original audio files were SHA-1 verified.
See minecraft-audio-v8.json for the additional paths and hashes.
These resources are not covered by the Three.js MIT license.

User-provided material
----------------------------------------
Blockopia logo: user-provided image, background removed to transparent PNG.
The lettering and colors follow the provided logo.
Exploration music: user-provided quiet_exploration_careful_v3.mp3
(approximately 64 seconds), embedded as looping background music.

Three.js
----------------------------------------
Three.js is bundled into index.html for offline operation.
Copyright and MIT license: see Threejs-MIT.txt.

Netherite textures added in v9
----------------------------------------
Minecraft Java Edition 1.16.5 / Mojang Studios / Microsoft.
Unmodified tool, item armor, and player armor textures, embedded for offline use.
Source mirror: https://github.com/InventivetalentDev/minecraft-assets/tree/1.16.5/assets/minecraft/textures
See netherite-textures-v9.json for individual source URLs and SHA-256 hashes.
